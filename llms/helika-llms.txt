# Helika

> Helika is a game and brand analytics platform (originally built for web3 and blockchain games) that helps studios, sports teams, and entertainment brands collect and act on player and community engagement data. Its Analytics Service API ingests gameplay and engagement events via a single events endpoint, instrumented by first-party Unity, Unreal Engine, and Web SDKs. Helika also operates Helika Evolve, an AI-character platform for brand-safe interactive characters.

Provider-published llms.txt: https://docs.helika.io/llms.txt (developer docs index, includes OpenAPI reference) and https://www.helika.io/llms.txt (marketing site).

## APIs
- [Helika Analytics Service](https://docs.helika.io/): POST /events/ event ingestion API, x-api-key header auth. Base URL https://events.analytics.helika.io
